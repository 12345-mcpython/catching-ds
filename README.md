# catching-ds
我要抓鱼，B 站太多鱼了！！！

由于最近 B 站增加了大量的 ai 机器人 (ds 为主), 使得评论区泛滥了一堆 ds 的无意义评论, 本项目就是来抓这些鱼的. 注意本项目采集 mid.

使用了 [这里](https://github.com/bggRGjQaUbCoE/PiliPlus/issues/3681) 的部分 mid.

## 使用方法

文件在仓库根目录下的 `fish.json` 下.

如果你的 B 站客户端是 [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus) 你可以使用本地拉黑来屏蔽这些用户.

如果使用其他或者官方客户端可以自己寻找方法.

另外 [bilibili-dafeiyu-blocker](https://github.com/ybyz2/bilibili-dafeiyu-blocker/) 是根据内容进行筛选, 本项目为账号定向屏蔽, 不要与本项目混淆. 同样也建议与本项目合用, 增强屏蔽效果.

## 注意

本项目为人类肉眼搜集, 有错误请原谅.

## 标准

依据 头像 昵称 评论内容进行筛选.

从上到下权重依次降低.

1. 评论很 AI 的
2. 头像包括大肥鱼相关内容的 
3. B 站等级 lv2-lv3
